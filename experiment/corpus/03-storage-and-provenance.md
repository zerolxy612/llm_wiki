# 存储分层与来源追溯

本文是原创实验资料，不包含真实用户数据。

raw/sources 是证据层；wiki 是生成的知识层；查询索引是加速层。schema.md 描述页面结构，purpose.md 描述研究目的，它们是控制信息，不应与查询索引混为一层。Wiki 允许人工维护，但所有重要主张应能追到原始来源。

wiki/index.md 提供入口，overview.md 提供全局概览，log.md 记录操作。实体页描述命名对象，概念页解释方法，来源页概括单份资料，综合页比较多个来源。YAML frontmatter 中的 sources 保留来源关系，wikilink 连接页面。

删除一个来源时，共享概念如果仍有其他来源支持，应保留页面并移除已删除的来源引用。索引可重建不代表重建免费：向量嵌入仍消耗时间和计算或 API 费用。
